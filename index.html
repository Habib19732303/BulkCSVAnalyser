❓Help & guidance
What is this tool?
A live online, 100% browser-based CSV editing and analysis utility. Upload, clean, split, filter, compare and export CSV files — all processing happens entirely on your device. Every file you download is saved directly to your own system. No data is ever sent to a server, stored in a database, or seen by anyone else. No backend. No tracking. No accounts required.
Supported email column names (auto-detected)
Email, EmailAddress, Mail, UserPrincipalName, UPN, PrimarySmtpAddress, SignInName, ProxyAddresses, Username, User
Domain types
Primary Org Domain Public Sector (.gov.uk) Education (.ac.uk) Charity/Org (.org.uk) External
Offline & dependency notes
  • Core analysis, filtering, comparison, and CSV downloads work fully offline
  • ZIP export uses JSZip CDN — if unavailable (no internet), files download separately with a short delay
  • Google Fonts uses CDN — if unavailable, the app falls back to system fonts automatically
  • Files are previewed up to 300 rows in browser — full data is always exported
  • For very large files (>10,000 rows) allow a few seconds for processing
Safe filename convention
company.com → domain_company_com.csv
dept.org.uk → domain_dept_org_uk.csv

✏️ About this tool
📄

Bulk User CSV Analyser was created by Habib ur Rehman as a practical local-use tool to make everyday IT support tasks faster, easier, and more accurate. The tool was designed from real support scenarios where large CSV files, user email lists, domain filtering, comparison checks, and export formats need to be handled quickly and carefully.

The aim of this tool is to reduce manual checking, save time, and help IT colleagues work more confidently with bulk user data. It runs fully in the browser, meaning files are processed locally and are not uploaded or stored online.

This is a personal productivity tool and not an official organisation-wide system. Users should handle all data according to their own organisation's local information governance and data protection policies.
